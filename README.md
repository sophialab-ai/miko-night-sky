# ミコと一緒に歩く「自分のことば」

夜空を歩きながら、自分の言葉をそっと拾う体験アプリです。

ミコと一緒に夜空を歩き、7つの問いに答えていきます。
答えた言葉はひとつずつ「ことばの結晶」になって、光の道に置かれていきます。
最後に、その日拾った言葉をまとめて眺め、PDFとして持ち帰れます。

## このアプリがしないこと

このアプリは、利用者を**診断しません**。

- 分析・要約・性格分類・スコアづけはしません
- 「あなたは○○です」「本当は○○を求めています」のような意味づけはしません
- 答えなかったことを、こちらから補いません

本人が書いた言葉を、そのまま本人へ返します。それだけの場所です。

## 使い方

1. アクセスコードを入れて「アクセスコードを確認」
2. 「ミコと歩きはじめる」（この時点で1回ぶんを使います）
3. 7つの問いに答える（思いつかない問いは飛ばせます）
4. 拾った言葉をまとめて見る → ふりかえり
5. PDFで持ち帰る
6. よければ、体験後のアンケートへ

途中でブラウザを閉じても、同じ端末・同じブラウザなら続きから歩けます。
途中再開は、新しい1回として数えません。

## あなたが書いた言葉について

**入力した言葉は、運営側には送られません。**

| どこにあるか | 内容 |
|---|---|
| あなたのブラウザの中（localStorage） | 7つの問いの回答・追加質問・ふりかえり・進行状況 |
| PDF | 上記のうち、あなたが答えたもの |

- 回答本文をサーバーへ送る処理は、アプリの中にありません
- アンケート（Googleフォーム）にも、アプリ内の回答は渡していません。フォームに届くのは、フォーム画面であなた自身が書いた内容だけです
- 端末に残る回答は、**最後に操作した日から7日**で自動的に消えます
- 終わりの画面の「この端末に残っている回答を削除する」を押せば、その場ですぐ消せます

## ブラウザについて

スマートフォン（縦画面）を前提に作っています。パソコンでも動きます。
最新のSafari・Chrome・Edgeで確認しています。

PDFは、ブラウザの印刷機能（A4横・白ベース）で作ります。
「PDFとして保存」を選んでください。

## 技術的なこと

HTML / CSS / JavaScript だけで動きます。
外部のライブラリ・CDN・解析サービスは使っていません。

外部と通信するのは、次の2つだけです。

- アクセスコードの確認と、利用回数の管理（Google Apps Script）
- 体験後アンケートを開く（Googleフォーム／新しいタブで開きます）

```
index.html      画面の骨組み
styles.css      夜空・結晶・PDFのスタイル
intro.css       導入アニメーション
app.js          体験全体の進行
js/config.js    アンケートURLなどの設定
js/questions.js 7つの問いと、結晶の置き場所
js/storage.js   ブラウザ内の保存（回答本文はここまで）
js/api.js       アクセスコードの確認・開始
js/ui.js        画面切り替えと演出
js/pdf.js       PDFの組み立て
js/intro.js     導入アニメーション
assets/images/  ミコ・結晶・背景
```
